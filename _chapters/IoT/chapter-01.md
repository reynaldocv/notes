# Commands to install MQTT broker and client 

# In RaspBerry Pi

```bash
sudo apt-get update
sudo apt-get install mosquitto mosquitto-clients
sudo systemctl enable mosquitto.service
sudo systemctl start mosquitto.service
```

Install mqtt-explorer in your computer to test the MQTT broker.
```bash 
sudoa apt-get install mqtt-explorer
```
